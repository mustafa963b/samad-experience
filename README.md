# SAMD — صمد

تجربة عربية تفاعلية للسبح المعطّرة والإهداء. تصميم متجاوب، حركة مرتبطة بالتمرير، معاينة ألوان الفوّاحة، ومحاكاة تجربة بطاقة NFC.

## المعاينة
https://mustafa963b.github.io/samd-experience/

## التشغيل
الموقع مبني من HTML وCSS وJavaScript، ويعمل على استضافة ملفات ثابتة. افتح index.html عبر خادم محلي أو GitHub Pages.

## ملاحظات
التجربة عرض تسويقي. أزرار التسوق تفتح متجر صمد الأصلي. صور الحملة مولدة بإلهام من مراجع العلامة؛ تفاصيل الفوّاحة وحركتها توضيحية. عرض NFC محاكاة بصرية.

## الأصول
الشعار والمراجع من مالك المشروع. Noto Sans Arabic وفق SIL Open Font License. GSAP وScrollTrigger وفق https://gsap.com/standard-license/ .
